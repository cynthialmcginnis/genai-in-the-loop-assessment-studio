# GenAI-in-the-Loop Assessment Studio

Faculty paste or upload any assessment (essay, problem set, lab, presentation, debate, role-play, case study, project, and more) and its learning outcomes. The studio:

- classifies each learning outcome by the thinking its verb asks for, and flags vague verbs;
- reads the assessment for features that make it easier or harder for GenAI to do the work without the learning;
- ranks eleven GenAI-in-the-loop designs by fit, each with a copy-ready prompt filled with the faculty member's details, what students submit, how to grade, and a no-GenAI route;
- drafts a student-facing GenAI-use expectation;
- builds a deeper-analysis prompt to paste into the faculty member's own permitted GenAI tool;
- exports the plan as .html or .txt.

Everything runs in the browser. Nothing is uploaded or stored. It works offline once loaded.

Companion tool for the Workshop-in-a-Box "Beyond AI Detection: Redesigning Authentic Assessments for the GenAI Era," by Molly Barra and Cynthia McGinnis, USM Generative AI Pedagogy Fellowship Program, 2026-2027. Draft.

The analysis is rule-based. It suggests designs; it does not make any assessment secure or prove who did the work.
